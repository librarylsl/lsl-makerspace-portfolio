LSL MAKERSPACE

A six-year learning journey where students discover, create, code, design, engineer and innovate.

Explore Our Journey Maker Gallery
Our Approach

Learn Through Making

MakerSpace provides opportunities for students to explore ideas, solve problems, use technology, build prototypes and reflect on their learning.

Explore

Ask questions, investigate and discover how things work.

Create

Transform ideas into designs, prototypes and digital creations.

Test

Test ideas, identify problems and learn from mistakes.

Improve

Debug, redesign and make solutions more effective.

EXPLORE → THINK → DESIGN → MAKE → TEST → DEBUG → IMPROVE → SHARE

Portfolio Progression

MakerSpace Digital Portfolio Maturity Model

Year Maker Stage Student Statement Typical Evidence
Year 1 Discover I can explore and follow instructions. Algorithms, drawings, photographs, simple reflection.
Year 2 Create I can design and create a solution. Problem, design, creation, testing and improvement.
Year 3 Code I can use code to make things happen. Flowcharts, Scratch, micro:bit code and debugging evidence.
Year 4 Design I can combine design, coding and technology. Tinkercad, micro:bit, sensors, prototypes and iteration.
Year 5 Engineer I can build and test a functional system. Engineering design, Arduino, circuits, testing data and prototypes.
Year 6 Innovate I can develop a solution to a real-world problem. Research, engineering, physical computing, AI, testing and presentation.
